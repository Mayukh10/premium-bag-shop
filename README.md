# Premium Bag Shop 👜

Welcome to the **Premium Bag Shop**! This is a full-stack e-commerce application built using the MERN (MongoDB, Express.js, EJS, Node.js) stack. The platform allows users to browse premium bags, view product details, and manage their shopping carts seamlessly.

---

## Features ✨

- **User-Friendly Interface**: Clean and responsive design for a seamless shopping experience.
- **Dynamic Views**: Rendered using EJS for server-side templating.
- **Product Management**: Browse, filter, and search through a wide range of premium bags.
- **Shopping Cart**: Add, remove, and adjust quantities of products in the cart.
- **REST API**: Efficient data handling and real-time updates.
- **Backend Focus**: Robust backend setup with API integration.

---

## Technologies Used 🛠️

### Frontend:
- **EJS (Embedded JavaScript)**: Server-side templating for dynamic HTML rendering.
- **HTML5/CSS3**: To structure and style the application.
- **Bootstrap**: For responsive and modern UI components.

### Backend:
- **Node.js**: JavaScript runtime environment.
- **Express.js**: Fast and lightweight web framework.
- **MongoDB**: NoSQL database for efficient data storage and retrieval.
- **Mongoose**: For modeling and managing database interactions.
